# S63 实验室场景迁移到 Isaac Sim 6

这一版用于快速确认迁移效果：直接让 Isaac Sim 6 的 MJCF Importer 读取
`lab_sence_static_with_box.xml`，并生成 USD。它会带入当前 MJCF 中的 S63
轮臂机器人、实验室、货架、托盘、45 个自由箱体、AprilTag 贴图和摄像机定义。

这不是最终的高保真标定版。MuJoCo 与 PhysX 的接触、摩擦、阻尼和执行器模型并
不完全相同；第一轮的目标是先检查比例、坐标、关节、碰撞和贴图是否完整。

## 1. 确认代码目录已挂载到容器

以下命令在服务器宿主机执行：

```bash
docker inspect isaac-sim \
  --format '{{range .Mounts}}{{println .Source "->" .Destination}}{{end}}'
```

输出中应包含本项目目录，并且挂载模式是可写。记下箭头右侧的容器内路径。

## 2. 导入 MJCF

进入容器：

```bash
docker exec -it isaac-sim bash
```

在容器中进入本目录并执行：

```bash
cd <容器内项目路径>/src/demo/ISV_grab_box
bash isaac_sim/import_mjcf.sh
```

脚本默认使用 `/isaac-sim/python.sh`，所以不要在宿主机直接运行
`"$ISAAC_SIM_ROOT/python.sh"`。导入输出位于：

```text
isaac_sim/generated/mjcf_baseline_年月日_时分秒/
```

每次运行使用新目录，不会覆盖上一次结果。脚本还会先检查所有 XML、STL 和
AprilTag PNG 是否存在。需要额外传入官方导入器参数时，可以直接追加，例如：

```bash
bash isaac_sim/import_mjcf.sh --merge-mesh
```

第一轮不建议使用 `--collision-from-visuals`，因为当前 MJCF 已有显式碰撞几何。

## 3. 查看效果

最稳妥的方式是在当前已经运行的 Isaac Sim GUI 中选择 **File > Open**，打开
刚生成目录中的主 USD。

如果容器允许启动第二个 Kit/GUI 实例，也可以运行：

```bash
bash isaac_sim/preview_usd.sh
```

无窗口检查：

```bash
bash isaac_sim/preview_usd.sh --headless --seconds 10
```

指定某个 USD：

```bash
bash isaac_sim/preview_usd.sh \
  --usd /容器内绝对路径/lab_sence_static_with_box.usd
```

## 4. 第一轮验收

依次检查：

1. S63 出现在 `(1.5, 0, 0)` 附近，朝向和 MuJoCo 一致。
2. 4 个轮组、14 个手臂关节及固定 D-hand 外观都存在。
3. 地面 AprilTag 09–18、货架 AprilTag 01–04 可见且方向正确。
4. 货架上 9 个箱体及托盘上 36 个箱体齐全；目标箱
   `lab_target_box` 在 `(2.454, 0, 0.780)` 附近。
5. 点击 Play 后机器人或箱体没有爆飞、穿透、持续抖动。
6. 基座、头部和左右手腕摄像机是否保留；导入器未保留时将在第二阶段按传感器
   标定参数重建。

如发生爆飞，先暂停仿真并保存 Console 日志与问题画面，不要先随意调质量或
摩擦参数；这些信息用于定位 PhysX 接触、惯量或关节驱动的差异。

## 6. 灵巧手搬箱演示面板（方案一）

当前面板适配最终左右换位布局 `isaac_sim/lab.usd`，目标物体固定识别为
`grab_box`。机器人会平滑
靠近桌面，将两只固定灵巧手移动到箱体两侧，再通过双掌接触、夹紧力和摩擦将动态
箱体垂直抬升 150 mm，随后以 10°/s 的最大角速度和 6°/s² 的角加速度原地转身
180°，再沿负 X 方向
抓稳并抬升后，底盘先沿来路直线后退 0.45 m，避开取货桌与相邻箱堆，再原地转身并
直线运输到后方 `rack2` 前的安全预放置位。随后机器人通过膝、腿和腰俯仰关节的
协调运动保持上半身竖直并抬高箱体，驶入第三层后由躯干继续竖直抬高、双臂沿连续
向下 IK 路径同步下降到层板，使肘部避开货架导轨，再向两侧打开固定灵巧手。箱体接触
第三层并开始沿滚筒坡道滑动后，机器人保持躯干和双臂
高位先退出货架，离开货架后依次放下双臂、降低躯干并恢复初始姿态；完成后自动暂停
在 `DEMO_COMPLETE`。
控制器不会逐帧设置箱体位置，也不会建立箱体跟随轨迹。由于当前
USD 中没有手指关节，两只手使用由可见
掌面和其余四指网格生成的凸包碰撞体，整体等效为一个双侧平行夹爪；没有跨越
手掌与箱壁空隙的隐藏碰撞垫。为避免导入时的固定拇指姿态穿入箱壁，控制器在 Session
Layer 中将左右拇指根部各向掌背收回 25 mm，并向下移动 25 mm，使弯曲的拇指尖在
放置阶段避开箱体上沿；拇指不再参与夹持碰撞。左右手的食指、中指、无名指和小指
根据左右手非严格镜像的实际间隙分别标定八根手指的绝对固定轻触角；右手食指、
中指、无名指和小指约为 5°、7°、10°、8°，左手采用更小的对应角度，避免穿入
箱壁。四个指尖在视觉上贴住箱壁但不会把箱体顶离掌面；夹持载荷
主要由左右掌面承担，四指只提供防滑和多点稳定支撑。
四指姿态每次都从 USD 原始四元数绝对计算，不会因为反复点击 `Play From Start` 或
`Reset to Start` 而逐次累加弯曲角。
左右可见掌面还各自向箱体方向增加 6 mm 固定预压，以补偿放置下降阶段的关节跟踪
误差；预压直接作用于掌面网格，没有额外的隐藏碰撞垫。
进入放置下降阶段后，箱体物理角阻尼由 80 临时提高到 160，以消耗手臂中段姿态切换
产生的旋转摆动；接触第三层后会清除线性和角阻尼，让箱体自由滑动。箱体始终是动态
刚体，未锁定姿态，也没有设置跟随轨迹。
手掌位置和夹持宽度不变，手指在运行过程中仍保持不动。所有刚体、
物理材质、碰撞和姿态调整均不会修改 `lab.usd` 文件。

使用方法：

1. 在 Isaac Sim 中打开 `isaac_sim/lab.usd`。
2. 打开 **Window > Extensions**，在 Extension Search Paths 中添加本目录下的
   `isaac_sim/exts` 绝对路径。
3. 搜索并启用 **Kuavo Dexhand Box Carry Demo**。若旧的
   **Kuavo Box Carry Demo** 仍在运行，请先将其禁用，避免两个控制器同时发指令。
4. 在英文面板中点击 **Play From Start**。
5. 状态显示 `DEMO_COMPLETE` 后，检查 `grab_box` 是否沿 `rack2` 第三层滑入并停稳，以及
   双手是否已经退出货架、机器人是否恢复姿态。

物理夹取的当前基准参数为：箱体质量 1 kg、掌面静/动摩擦系数 5.0、箱体在货架上的
静/动摩擦系数均为 0、CPU PhysX
120 Hz。可运行下面的无界面回归测试，测试会实际执行完整动作并要求箱体至少抬升
120 mm、底座完成 180° 转身、箱体进入第三层、释放后沿坡道滑动至少 50 mm 并最终
停留在货架上：

```bash
/home/csc/isaacsim/python.sh \
  /home/csc/workspace/projects/kuavo_ws_csc/src/demo/ISV_grab_box/isaac_sim/smoke_test_dexhand_grip.py
```

最终 `lab.usd` 已将机器人、`rack2`、`rack3_flow_rack`、`box_storage_pallet`、
全部 `pallet_box_*` 和 `grab_box` 整体移到原另一货架所在的 Y 向工位；同时将
`rack1` 及货架上的全部九个 `rack2_box_*` 箱体移到原作业线工位。两组沿 Y 轴
对调 1.501847 m，组内相对位置、朝向和高度不变。`rack2` 的四块层级标牌保持在
名称所表示的货架正 X 端，各自的 Y、Z、尺寸和朝向不变。
覆盖前的原场景备份为 `lab_before_final_layout.usd`；`create_swapped_lab.py` 会检测
当前布局并拒绝对最终 `lab.usd` 再次换位，以免坐标重复偏移。

可以反复点击 **Play From Start** 从场景原始状态重播；**Pause** 与 **Resume**
用于中途暂停和继续。运输阶段使用 0.15 m/s 的最大速度和 0.03 m/s² 的加速度；
箱体设置 40.0 的角阻尼；货架前的躯干抬升使用 12 秒五次曲线，并自动检查夹持运输
全程总倾角不得超过 7.5°，以抑制抬升、转身和运输时的倾斜；当前回归的最大倾角
约为 4.12°，发生在取箱后退阶段。

扩展的刚体、碰撞、底盘锚点和动态 Transform 只写入匿名 Session Layer。扩展启用、
Reset、播放、暂停、完成和报错期间 Edit Target 都保持在该层，保证 PhysX 动态位姿
不会写入 `lab.usd`。关闭扩展时会先在 Session Layer 中停止 PhysX，再恢复到启用前的
持久层（通常是 `lab.usd` 根层）。因此修改和保存 USD 前必须先关闭扩展；不要只暂停后
直接保存。最稳妥的编辑顺序是：关闭扩展，关闭当前 Stage（若旧场景提示保存则选择
**Don't Save**），重新打开 `lab.usd`，在 Root Layer 中编辑并保存，然后重新启用扩展。
Session Layer 内容会在关闭场景时被丢弃。
箱体复位通过 Isaac 刚体世界位姿接口完成，不依赖 `grab_box` 必须具有单独的
`xformOp:translate`；同时扩展会把打开场景时缓存的箱体局部矩阵写入 Session Layer，
该写入严格发生在 Timeline 和 PhysX 启动之前，确保 Reset 恢复正确初始位姿且不会
覆盖动态刚体运动。编辑器保存时重排、合并 USD 变换栈不会阻止 Demo 启动，也不会
把复位矩阵保存进 `lab.usd`。
底盘运动使用的临时固定关节与 PhysX 动态位姿在播放期间使用同一个 Session Layer；
因此轮子与底盘会同步运动，也不会把播放轨迹保存进 `lab.usd`。
并根据当前 `rack2` 与 `grab_box` 的包围盒自动计算停车坐标；箱体前沿与货架保留
0.42 m 预对位距离。当前 STEP 货架的自动碰撞近似会把层间开口封闭，因此控制器只在
目标货架 `/World/rack2` 采用与另一货架 `/World/rack1` 完全相同的碰撞模式：启用
1451 个 STEP `Xform` 分件碰撞，并统一使用 `approximation=none`。`rack2` 独有的
四块层级标签只保留视觉，Cube 碰撞被关闭。每次 Reset 都会重新写入这些状态，避免
旧扩展在 Session Layer 中留下“碰撞关闭”的设置。没有创建承托面或其他隐形碰撞体；
`grab_box` 直接与货架本体接触，并保持受重力、摩擦和碰撞控制的动态刚体。
进入货架前，双臂先在保持箱体高度和朝向的条件下向前伸直
75 mm；控制器随后根据新的“箱体—底盘”相对位置计算插入停车点，因此底盘会在
放置前就停在距离货架更远的位置。放置阶段底盘完全固定，不会边放边后退。
放置使用 12 秒协调轨迹：躯干竖直抬高 80 mm，双臂相对躯干下降 210 mm，因此
手掌在世界坐标下降 130 mm，并保持更伸直的肘部姿态以避开第三层黄色导轨。
箱底接触承载面后，双掌停止提供碰撞夹持，箱体沿坡道滑入，随后机器人保持高姿态后退。货架
视觉不变，`grab_box` 仍是质量 1 kg 的动态刚体，放置过程仍由重力、接触和摩擦完成；
另一侧货架上名称为 `rack2_box_*` 的九个箱体不再被扩展强制固定，会从初始位置在
重力作用下自由下落；货架、桌子和托盘等设施仍保持固定。
不会修改 `lab.usd`。

控制器会在箱体到达承载面上方约 32 mm、尚未发生视觉接触时主动停止手臂，关闭
手部接触并临时提高箱体线性阻尼，让箱体缓慢落到承载面；不再让箱体先顶住货架并
等待 18 秒超时。缓降阻尼会一直保持到箱底距离承载面小于 1 mm，避免最后一小段
突然加速。接触货架后会清除缓降阻尼，并使用在 PhysX 初始化前绑定的零摩擦箱体材质；
抓取所需的高摩擦只保留在双掌和四指，因此不妨碍箱体沿静态滚筒坡道滑动。导入的
第三层前后两段滚筒之间存在会错误挡住箱体的 STEP 连接件碰撞，控制器只在 Session
Layer 中关闭这些内部连接件的碰撞，视觉、两段滚筒、侧导轨和末端挡板保持不变。
由于滚筒本身是不会旋转的静态网格，控制器在箱体到达 X=-2.55 m 前施加 0.15 N 的
沿坡补偿力，等效补偿自由滚筒缺失的转动；箱体位置和姿态仍完全由刚体、重力和货架
碰撞求解。箱体开始
滑动后，机器人保持整套手臂姿态直接退出，并比原预放置停车点额外
后退 200 mm；开始后退前先静止 1.5 秒消除伸展手臂的残余摆动，后退改用 12 秒
零速度、零加速度起止的五次曲线，避免梯形速度起步时的加速度突变。确认完全远离
货架后才收回双臂并降低躯干。由于导入关节驱动在伸展姿态下仍会产生俯仰跟踪误差，
从箱体释放到完全退出货架期间，控制器会每帧锁定所有非轮式关节并清零关节速度；
底盘和车轮仍正常播放平滑后退，但躯干与双臂不会再因惯性向前点头。离开货架后
解除锁定，恢复正常关节驱动完成收手。

放置结束严格按“停止手部碰撞夹持、箱体自由滑入、保持高姿态后退、双臂折叠、躯干下降”
的顺序执行；手部搬运碰撞在箱体开始缓降时关闭，以避免机械手阻挡箱体滑动。
当前基准中，箱体由 `/World/rack2` 的 STEP 本体碰撞承托，最终位置约为
`(-2.722, 4.149, 1.183) m`，沿货架滑入约 `0.894 m`，最终静止速度为 `0 m/s`。
控制器使用第三层标牌下表面
上方 25 mm 作为下降参考高度，并允许原始多滚筒碰撞首次接触存在 30 mm 状态判断带；
该判断带不参与碰撞求解，箱体随后仍会依靠重力落到真实货架几何上。
箱体完成插入、即将松手下落时只为 `grab_box` 启用 CCD；不再修改箱体或货架的
`contactOffset`，因此不会改变夹持倾角和插入深度。
放箱后的 0.894 m 平滑后退会按照实际移动距离直接累计四个轮子的可见转角，并将写入
PhysX 的关节角按 `2π` 包裹；当前回归累计转角约为 `6.874 rad`，因此轮子会明显转过
一整圈，同时不会超过 PhysX 转动关节的目标角范围。
